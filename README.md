# Enterprise Data Reconciliation & Business Intelligence Dashboard
End-to-End ETL Pipeline using SQL, Regex, Pandas &amp; Python

## Project Overview

This project demonstrates an end-to-end ETL (Extract, Transform, Load) pipeline using Python, SQL, Regular Expressions, and Pandas.

The project extracts user information from a SQLite database, parses unstructured server logs, reconciles financial transactions using exchange rates, and generates business insights through data visualization.

## Tech Stack

- Python
- SQLite
- SQL
- Pandas
- Regular Expressions (Regex)
- Matplotlib
- Seaborn
- Jupyter Notebook

## Features

- Extracted latest active users using SQL Window Functions.
- Parsed unstructured server logs using Regular Expressions.
- Performed ETL and financial reconciliation.
- Converted EUR transactions into USD.
- Generated business insights using Pandas.
- Created visualizations using Matplotlib and Seaborn.

## How to Run

1. Clone the repository.
2. Install the required libraries.
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Place the datasets in the `data` folder.
5. Run all notebook cells from top to bottom.
