# Enterprise Data Reconciliation & Business Intelligence Dashboard
End-to-End ETL Pipeline using SQL, Regex, Pandas &amp; Python

## Project Overview

This project demonstrates an end-to-end ETL (Extract, Transform, Load) pipeline using Python, SQL, Regular Expressions, and Pandas.

The project extracts user information from a SQLite database, parses unstructured server logs, reconciles financial transactions using exchange rates, and generates business insights through data visualization.

## Tech Stack

- Python
- SQLite
- SQL
- Pandas
- Regular Expressions (Regex)
- Matplotlib
- Seaborn
- Jupyter Notebook
